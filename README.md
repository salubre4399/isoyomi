# 磯読み（ISOYOMI）

磯釣りの下見に使う個人用の地図。海岸地形・等深線・陸の勾配・底質・藻場・潮位を1画面で見る。

公開しているのは、アプリ本体と公的機関のオープンデータだけです。

## データの出どころ

- 海洋状況表示システム「海しる」（海上保安庁） — 海岸線ESI区分／等深線／底質／藻場／海底障害物／漁業権区域ほか
- 気象庁 潮位表 — 験潮所の毎時潮位・満干潮
- 国土地理院 — 地理院タイル（航空写真・地図）、標高タイル（DEM10B）
- Copernicus Sentinel-2（ESA） — 浅場の推定
- Open-Meteo — 波・風・海流の予報

## 注意

等深線は20m刻みで、磯際の地形は表していません。衛星の水深推定は濁り・白波・藻場に弱く、
とくに磯際0〜数mが最も外れます。歩いて行けるか、安全かどうかは一切判定していません。
